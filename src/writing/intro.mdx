Hi, I'm Deepanshu. I'm a full-stack engineer working mostly on WebRTC, real-time communication, and distributed systems.

I spent 4.5 years at [Huddle01](https://huddle01.com) as the Founding and Lead Engineer, leading a team of 10-12 engineers. Some of the things we built there:

- **WebRTC & WebSocket infrastructure**

  Built "Cascading", a horizontally partitioned WebRTC SFU setup (similar to database sharding) that let us handle 10,000+ concurrent users per room with sub-100ms latency.
  Moved signaling from JSON to Protobufs, cutting message sizes by ~60% and more than doubling throughput per WebSocket instance (running on [uWebSockets](https://github.com/uNetworking/uWebSockets.js)).

- **NFT indexing service**

  Built an NFT indexer because [Phantom](https://phantom.com) acquired [SimpleHash](https://simplehash.com) and shut it down. Wrote it in Rust for multithreaded indexing and cached a few terabytes of NFTs in S3.

- **SDKs**

  Built frontend and backend SDKs for our real-time infra, aiming for simple DX while keeping them flexible enough for custom setups.

- **Recording service**

  Built a recording service using FFmpeg, Puppeteer, Xvfb, PulseAudio, Node.js, and TypeScript, deployed on Kubernetes so pods could autoscale under high load.

- **Deployment pipeline**

  Moved services off AWS (Lambda and Fargate) onto bare-metal servers to save costs, and set up the CI/CD pipeline for bare-metal deploys.

- **Monolith to microservices**

  Broke up our monolith into smaller event-driven services talking over gRPC, which made it easier to scale independently, ship without downtime, and split ownership as the team grew.

- **Client-facing products**

  Led the team building the Huddle01 meeting app, dashboards for managing meetings, Chrome extension, Google Calendar add-ons, node sales platform, and [farhouse](https://house01.fun).

## Side Projects

- **Pingo** - [https://github.com/deepso7/pingo](https://github.com/deepso7/pingo)

  A Rust library for peer-to-peer latency measurement using STUN and UDP hole punching. This helped me figure out a very basic idea on how I can calculate latency between 2 peers.

- **Matrix** - [https://github.com/deepso7/matrix](https://github.com/deepso7/matrix)

  Rust based lib/api for spinning up lightweight microVMs using [**Firecracker**](https://firecracker-microvm.github.io) or [**Cloud Hypervisor**](https://www.cloudhypervisor.org). This helped me understand how microVMs work and how easily I can spin up microVMs.
